# 심연의 낚싯대

깊이 던질수록 괴물이 나오는 브라우저 낚시 게임이에요. `index.html` 파일 하나로 돌아가요.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 로그인과 클라우드 저장

처음 열면 로그인 화면이 떠요.

- **게스트로 시작**: 바로 플레이해요. 기록은 이 브라우저에만 저장돼요. 예전에 하던 기록도 그대로 이어져요.
- **구글로 로그인**: 기록이 Firebase(Firestore)에 저장돼서 **다른 기기에서 로그인해도 이어서** 할 수 있어요.
  - 게스트로 하던 기록이 있으면 처음 로그인할 때 이어갈지 물어봐요.
  - 인터넷이 끊겨도 이 기기에 먼저 저장하고, 다시 연결되면 클라우드에 올려요. 이름 옆 점이 초록이면 저장 완료, 노랑이면 저장 중, 빨강이면 실패예요.
- 한 번 고르면 다음부터는 바로 시작해요. 오른쪽 위 **로그아웃 / 계정 바꾸기**로 바꿀 수 있어요.

### 구글 로그인 켜는 법 (Firebase 무료 Spark 요금제로 충분해요)

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 **프로젝트 추가**를 눌러 프로젝트를 만들어요. (Google 애널리틱스는 꺼도 돼요.)
2. **빌드 > Authentication > 시작하기 > 로그인 방법**에서 **Google**을 사용 설정해요.
3. **빌드 > Firestore Database > 데이터베이스 만들기**를 눌러요. 위치는 `asia-northeast3 (서울)`을 추천하고, **프로덕션 모드**로 시작해요.
4. Firestore의 **규칙** 탭에 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여 넣고 **게시**해요. 각자 자기 기록만 읽고 쓸 수 있게 막아 줘요.
5. **프로젝트 설정(톱니바퀴) > 내 앱 > 웹(`</>`)**으로 웹 앱을 등록하면 `firebaseConfig` 객체가 나와요. 그 객체를 `index.html`의 `const FIREBASE_CONFIG = null;` 자리에 붙여 넣어요.
   ```js
   const FIREBASE_CONFIG = { apiKey: '...', authDomain: '...', projectId: '...', storageBucket: '...', messagingSenderId: '...', appId: '...' };
   ```
   이 값은 공개돼도 괜찮은 값이에요. 보안은 4번 규칙이 맡아요.
6. 게임을 올릴 주소를 **Authentication > 설정 > 승인된 도메인**에 추가해요. 예: `<아이디>.github.io` (`localhost`는 처음부터 들어 있어요.)
7. 파일을 그냥 더블클릭(`file://`)하면 구글 로그인이 안 돼요. GitHub Pages나 `python3 -m http.server 8000` 같은 웹 서버로 열어 주세요.

`FIREBASE_CONFIG`가 비어 있으면 구글 버튼은 비활성으로 보이고 게스트로만 시작할 수 있어요.

저장은 몇 초에 한 번으로 묶어서 보내기 때문에, 무료 한도(하루 쓰기 2만 회)를 넘길 일은 거의 없어요.

## 조작법

- **꾹 눌렀다 떼기**: 게이지만큼 깊이 던져요. 스페이스바도 돼요.
- **느낌표(!)가 뜨면 누르기**: 챔질해서 바늘을 걸어요.
- **누르면 감고 떼면 풀기**: 장력 바늘을 초록 구간에 맞추면 물고기 체력이 빨리 깎여요.
- **빨간 구간**까지 올라가면 줄이 끊어지고, 줄이 오래 느슨하면 물고기가 도망가요.

## 내용

- 낚싯대 7단계 (40m → 480m), 낚싯줄·미끼·작살 강화
- 수심 5구역, 223종 (몬스터와 보스 레비아탄 포함)
  - 구역마다 40종씩, 새 물고기 200종을 더했어요. 몸통·꼬리·등지느러미·무늬·입·눈·장식(수염, 뿔, 발광 미끼, 가시, 발광점 등)을 조합해 한 마리씩 다르게 그려요.
  - 같은 모습이 나오지 않게 고정된 시드로 만들기 때문에, 같은 물고기는 언제 봐도 같은 모습이에요.
  - 새 몬스터 10종도 들어 있어요 (구역마다 2종).
- 낚으면 물고기가 물 위로 높이 튀어 올라요. 낚시꾼이 머리 위로 번쩍 들어 올리면 팡파르와 함께 이름이 크게 떠요. 누르면 바로 넘길 수 있어요.
- 세 마리를 낚은 뒤부터 바다 괴물이 배를 습격해요
- 도감과 기록 탭
- 진행 상황은 브라우저(localStorage)에만 저장돼요
