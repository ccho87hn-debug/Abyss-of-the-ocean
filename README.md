# 심연의 낚싯대

깊이 던질수록 괴물이 나오는 브라우저 낚시 게임이에요. `index.html` 파일 하나로 돌아가요.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 로그인

처음 열면 로그인 화면이 떠요.

- **게스트로 시작**: 바로 플레이해요. 기록은 이 브라우저에만 저장돼요. 예전에 하던 기록도 그대로 이어져요.
- **구글로 로그인**: 구글 계정마다 기록을 따로 저장해요. 게스트로 하던 기록이 있으면 처음 로그인할 때 이어갈지 물어봐요.
- 한 번 고르면 다음부터는 바로 시작해요. 오른쪽 위 **로그아웃 / 계정 바꾸기**로 바꿀 수 있어요.

> 서버가 없는 게임이라 구글 로그인도 기록은 **그 브라우저 안에만** 저장돼요. 다른 기기와는 동기화되지 않아요.

### 구글 로그인 켜는 법

1. [Google Cloud 콘솔](https://console.cloud.google.com/apis/credentials)에서 **OAuth 클라이언트 ID**(웹 애플리케이션)를 만들어요.
2. **승인된 자바스크립트 원본**에 게임을 여는 주소를 넣어요. 예: `https://<아이디>.github.io`, 로컬 테스트는 `http://localhost:8000`
3. `index.html`의 `const GOOGLE_CLIENT_ID = '';`에 받은 클라이언트 ID를 넣어요.
4. 파일을 그냥 더블클릭(`file://`)하면 구글 로그인이 안 돼요. GitHub Pages나 `python3 -m http.server 8000` 같은 웹 서버로 열어 주세요.

클라이언트 ID가 비어 있으면 구글 버튼은 비활성으로 보이고 게스트로만 시작할 수 있어요.

## 조작법

- **꾹 눌렀다 떼기**: 게이지만큼 깊이 던져요. 스페이스바도 돼요.
- **느낌표(!)가 뜨면 누르기**: 챔질해서 바늘을 걸어요.
- **누르면 감고 떼면 풀기**: 장력 바늘을 초록 구간에 맞추면 물고기 체력이 빨리 깎여요.
- **빨간 구간**까지 올라가면 줄이 끊어지고, 줄이 오래 느슨하면 물고기가 도망가요.

## 내용

- 낚싯대 7단계 (40m → 480m), 낚싯줄·미끼·작살 강화
- 수심 5구역, 223종 (몬스터와 보스 레비아탄 포함)
  - 구역마다 40종씩, 새 물고기 200종을 더했어요. 몸통·꼬리·등지느러미·무늬·입·눈·장식(수염, 뿔, 발광 미끼, 가시, 발광점 등)을 조합해 한 마리씩 다르게 그려요.
  - 같은 모습이 나오지 않게 고정된 시드로 만들기 때문에, 같은 물고기는 언제 봐도 같은 모습이에요.
  - 새 몬스터 10종도 들어 있어요 (구역마다 2종).
- 세 마리를 낚은 뒤부터 바다 괴물이 배를 습격해요
- 도감과 기록 탭
- 진행 상황은 브라우저(localStorage)에만 저장돼요
